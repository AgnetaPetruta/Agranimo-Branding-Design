# Agranimo portfolio case study

Ready for GitHub Pages. No build step is required.

1. Unzip this package.
2. Create a public GitHub repository, for example `agranimo-brand-case-study`.
3. Upload the contents of this folder, including `index.html`, `style.css`, `app.js` and the complete `assets` folder, to the repository root. Upload the files, not the ZIP or its enclosing folder.
4. Commit the upload.
5. Open Settings > Pages. Under Build and deployment, select Deploy from a branch. Select `main` and `/ (root)`, then Save.
6. After deployment finishes, use the website URL shown in Settings > Pages.

All imagery and the dashboard video are included. Keep the folder structure intact. The video remains directly between RO5 and RO6.
